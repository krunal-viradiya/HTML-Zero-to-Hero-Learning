<h2>📖 About This Repository</h2>
<p>Welcome to the <strong>HTML: Zero to Hero</strong> repository! 🌐</p>
<p>Unlike other tutorials where you have to jump between dozens of folders and files, this repository takes a unique approach: <strong>Everything is packed into ONE single HTML file.</strong></p>
<p>Whether you are writing your very first line of code or you are a developer looking for a quick cheat sheet, this single file contains all the practical examples of HTML5 you will ever need. Just open it, read the code, and see the magic in your browser!</p>

<hr>

<h2>🔥 The Ultimate HTML Tags Dictionary</h2>
<p>As promised, here is the most comprehensive cheat sheet of HTML tags available in this repository. If you ever forget a tag, just refer to these tables!</p>

<h3>🧱 1. Document Structure & Metadata</h3>
<table border="1" width="100%" cellpadding="8" cellspacing="0">
  <thead>
    <tr bgcolor="#f2f2f2"><th align="left">Tag</th><th align="left">Description</th></tr>
  </thead>
  <tbody>
    <tr><td><code>&lt;!DOCTYPE html&gt;</code></td><td>Defines this document as an HTML5 document.</td></tr>
    <tr><td><code>&lt;html&gt;</code></td><td>The root element of an HTML page.</td></tr>
    <tr><td><code>&lt;head&gt;</code></td><td>Contains metadata, title, and links to stylesheets/scripts.</td></tr>
    <tr><td><code>&lt;title&gt;</code></td><td>Sets the title of the document (shows in the browser tab).</td></tr>
    <tr><td><code>&lt;meta&gt;</code></td><td>Defines metadata like character set, viewport, and SEO descriptions.</td></tr>
    <tr><td><code>&lt;link&gt;</code></td><td>Defines the relationship between a document and an external resource (e.g., CSS).</td></tr>
    <tr><td><code>&lt;style&gt;</code></td><td>Used to embed CSS styles directly in the HTML.</td></tr>
    <tr><td><code>&lt;script&gt;</code></td><td>Used to embed executable JavaScript code.</td></tr>
    <tr><td><code>&lt;body&gt;</code></td><td>Contains all the visible content of the web page.</td></tr>
  </tbody>
</table>

<h3>📝 2. Text Formatting, Phrasing & Code</h3>
<table border="1" width="100%" cellpadding="8" cellspacing="0">
  <thead>
    <tr bgcolor="#f2f2f2"><th align="left">Tag</th><th align="left">Description</th></tr>
  </thead>
  <tbody>
    <tr><td><code>&lt;h1&gt;</code> to <code>&lt;h6&gt;</code></td><td>Headings. <code>&lt;h1&gt;</code> is the most important, <code>&lt;h6&gt;</code> is the least.</td></tr>
    <tr><td><code>&lt;p&gt;</code></td><td>Defines a standard paragraph.</td></tr>
    <tr><td><code>&lt;br&gt;</code></td><td>Inserts a single line break.</td></tr>
    <tr><td><code>&lt;hr&gt;</code></td><td>Inserts a horizontal rule (a thematic dividing line).</td></tr>
    <tr><td><code>&lt;strong&gt;</code> / <code>&lt;b&gt;</code></td><td>Defines important/bold text.</td></tr>
    <tr><td><code>&lt;em&gt;</code> / <code>&lt;i&gt;</code></td><td>Defines emphasized/italic text.</td></tr>
    <tr><td><code>&lt;mark&gt;</code></td><td>Highlights text with a background color.</td></tr>
    <tr><td><code>&lt;del&gt;</code> / <code>&lt;ins&gt;</code></td><td>Defines deleted (strikethrough) and inserted (underlined) text.</td></tr>
    <tr><td><code>&lt;sub&gt;</code> / <code>&lt;sup&gt;</code></td><td>Defines subscript (e.g., H₂O) and superscript (e.g., x²).</td></tr>
    <tr><td><code>&lt;blockquote&gt;</code></td><td>Defines a section that is quoted from another source.</td></tr>
    <tr><td><code>&lt;code&gt;</code></td><td>Defines a piece of computer code.</td></tr>
    <tr><td><code>&lt;pre&gt;</code></td><td>Defines preformatted text (preserves spaces and line breaks).</td></tr>
  </tbody>
</table>

<h2>🛠️ How to Use This Repo</h2>
<p>Since everything is beautifully organized, getting started is incredibly easy!</p>
<ol>
  <li><strong>Clone the repository</strong> to your local machine:
    <br><br>
    <code>git clone https://github.com/krunal-viradiya/zero-to-hero-html.git</code>
    <br><br>
  </li>
  <li><strong>Open the folder</strong> in your favorite code editor (like VS Code).</li>
  <li><strong>Open the HTML files</strong> (<code>Basic.html</code> or <code>Advanced.html</code>) in your editor to see the code structure.</li>
  <li><strong>Run it in your browser!</strong> Just double-click the file, or use the <em>Live Server</em> extension in VS Code to see exactly how the code translates to a real webpage.</li>
</ol>
<p><em>Tip: Keep the browser and code editor side-by-side. Change a tag in the code, save it, and watch the magic happen live!</em></p>

<h2>💡 The Vision Behind This Repository</h2>
<p>When beginners start learning web development, they often get overwhelmed by complex folder structures, multiple files, and heavy documentation. Learning HTML shouldn't be complicated—it is the foundational language of the web, and it should be accessible to everyone.</p>
<p>I created <strong>HTML: Zero to Hero</strong> with a simple philosophy: <strong>Keep it simple, keep it powerful.</strong></p>
<p>Instead of jumping between different files to understand different concepts, this repository gives you a clean playground. You can scroll from top to bottom in the files, reading the heavily commented code, and simultaneously seeing the output in your browser.</p>
